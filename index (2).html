Backup / Restore

ডেটা আপোনাৰ ডিভাইচৰ ব্ৰাউজাৰত থাকে। মোবাইল আৰু কম্পিউটাৰৰ মাজত ডেটা স্থানান্তৰ কৰিবলৈ JSON Backup export কৰি আন ডিভাইচত import কৰক।

Backup-ত ছাগলীৰ তালিকা, ভেকচিন লগ আৰু স্বাস্থ্য ৰেকৰ্ড একেলগে থাকে। Import কৰিলে বৰ্তমানৰ ডেটাৰ ঠাইত Backup-ৰ ডেটা বহুৱাব; আগতে Export কৰি ৰাখক।

App-ৰ তথ্য

Offline ব্যৱহাৰৰ বাবে প্ৰথমে App-ৰ ফাইলসমূহ খুলি install/host কৰিব লাগিব। PWA install আৰু offline cache সাধাৰণতে HTTPS বা localhost-ত কাম কৰে; কেৱল ZIP-ৰ পৰা খোলা HTML-ত app-ৰ ডেটা চলিব পাৰে, কিন্তু install/offline cache সীমিত হ’ব পাৰে।
